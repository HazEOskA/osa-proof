## 2. Zaimplementowane, lecz niedomknięte

- **Mission Kernel:** FileMissionStore działa lokalnie; domyślny store w API nadal może być procesowy na Vercel.
- **Durable Execution:** kod + opcjonalny worker (wymaga NVIDIA key + ACK); Vercel Production nadal bez trwaleńszego workera.
- **NeurOSA:** remote wyłączone w lokalnym hoście; restart-readback pełnej usługi **UNKNOWN**.
- **Worker Host:** kod RemoteWorkspaceProvider + DockerWorkspaceProvider istnieje; pełny E2E z dwoma izolowanymi workerami **NOT PROVEN**.
- **Live Trace:** SSE działa; część śladów to metadane przeglądarki.

## 5. Ścieżka E2E dla czatu z ukrytym frameworkiem + warstwą dowodów

Cel: normalny czat (Jeverson) → deterministyczne narzędzie OSA lub Team Graph → zdarzenia → Evidence → ProofReceipt → niezależna weryfikacja.

**Minimalny lokalny E2E (P0):**

1. `osa doctor` — preflight PASS.
2. `osa dashboard` — host loopback.
3. W czacie wywołaj deterministyczne narzędzie (np. SHA-256 lub runtime inspect).
4. Sprawdź Live Trace / Proofs w UI.
5. Eksportuj bundle i zweryfikuj hashe offline (PROOF_EXPORTS_GUIDE).
6. Restart hosta i potwierdź, że plikowy store zachował misję (lokalnie).

**Pełny E2E (BLOCKED do zamknięcia):**

- Dwa realne workery (Docker) z tool_calls > 0.
- NeurOSA remote z restart-readback.
- Cross-device readback.
- Niezależny verifier poza runtime.

Szczegóły unified preview: [OSA_UNIFIED_RUNTIME_V1.md](./OSA_UNIFIED_RUNTIME_V1.md).
