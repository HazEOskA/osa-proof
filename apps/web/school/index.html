01 / Hero

Blok decyzyjny: w 5 sekund pokazać różnicę między „twierdzę” i „udowodniłem”. Obok copy siedzi panel Claimed vs Verified — to jest zapowiedź całego produktu.

OSA // DOWÓD ALBO NIC

Twój agent mówi, że działa. OSA mówi: udowodnij.

OSA to kontrakt plus warstwa dowodowa dla agentów. Koniec z „powinno działać”. Cztery poziomy dowodu, 120 kart operacyjnych i tryb godmode, kiedy robota jest ostra.

Zainstaluj OSA Zobacz drabinę dowodów
Claimed — to, co słyszysz Verified — to, co zostaje
  • „działa”
  • „build przeszedł”
  • „gotowe”
  • „przetestowane”
  • npm test → exit 0
  • plik istnieje w repo
  • git diff = lista plików
  • czyste środowisko, powtórzone

02 / Drabina dowodów

Serce produktu. Cztery poziomy dowodu — klikasz poziom i widzisz, co dokładnie trzeba wkleić, żeby na niego wejść. Interakcja: przełączanie poziomów.

Cztery poziomy. Zero wymówek.

Poziom dowodu rośnie tylko wtedy, gdy pojawia się artefakt. Nigdy za dobre słowo.

        06 / Społeczność
