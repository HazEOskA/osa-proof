Każda warstwa ma jedno zadanie i twardą granicę odpowiedzialności. Model proponuje, runtime egzekwuje, God Layer zatwierdza, rejestr pamięta, builder produkuje.

L00execution

APR — runtime wykonania

Przyjmuje manifest misji, wymusza kontrakt, uruchamia deterministyczne testy akceptacyjne i zapisuje Proof Bundle. Nie ufa logowi aktywności — liczy hashe i łańcuch zdarzeń.

manifest → walidacja → propozycja → egzekwowanie → materializacja → testy → proof bundle → weryfikator

recording
L01proposal

LLM Layer — warstwa propozycji

Model zwraca wyłącznie propozycję tekstu artefaktu. Runtime — nie model — decyduje o ścieżkach, typach, liczbie plików i limitach. Model nigdy nie rozstrzyga o ważności kryptograficznej.

proposal only
L02oversight

God Layer — nadzór i bramki

Zatwierdza plan, zanim cokolwiek się zmieni. Trzyma locki kontekstu, researchu i decyzji oraz rozstrzyga o push i deploy. Nic nie idzie dalej bez jawnej zgody.

gated
